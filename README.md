#  Weather App

A simple Weather App built using **Python** and **Tkinter** that displays real-time weather information for any city using the **OpenWeatherMap API**.

##  Features

* Search weather by city name
* Display current temperature
* Show weather condition
* Display humidity
* Show wind speed
* Display "Feels Like" temperature
* User-friendly GUI
* Error handling for invalid city names

##  Technologies Used

* Python 3
* Tkinter
* Requests
* OpenWeatherMap API

##  Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/Weather-App.git
```

2. Move into the project folder.

```bash
cd Weather-App
```

3. Install the required packages.

```bash
pip install -r requirements.txt
```

4. Get a free API key from **OpenWeatherMap**.

5. Replace the API key in `weather.py` with your own key.

6. Run the application.

```bash
python weather.py
```
